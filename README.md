# AI-Based Water Quality Monitoring

## Project Description
This project focuses on monitoring water quality using sensor data and Artificial Intelligence.

## Parameters
- pH
- Turbidity
- Dissolved Oxygen
- Conductivity
- Temperature

## Technologies Used
- Python
- Machine Learning
- Firebase

## Project Objective
To classify water quality as Safe, At Risk or Unsafe.

## Project Status
Academic Project
